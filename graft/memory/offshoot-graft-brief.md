# GRAFT offshoot brief — last-root nursery

The LLM dump proposed S3, Neo4j, FAISS, KMS, HSMs, and a 28-week filer.

**GRAFT is the offshoot of that idea**, not the enterprise stack.

| LLM dump | GRAFT offshoot |
|---|---|
| S3 + Neo4j + vector DB | Local CAS + JSON ledger under `graft/state/` |
| On-chain content / frequent anchors | Last-root Merkle + short `§GRAFT§` tags only |
| Autonomous refinement commits | Human `/graft activate` then money-gated `/graft think` |
| Merge into production memory | Harvest mark only — never writes `vita/` |
| IAM / KMS | Dedicated Telegram bot + GRAFT piggy (paper by default) |

## How to file and activate

1. `/graft insert` (or `--cmd`) files the raw prompt losslessly.
2. `/graft list` shows filed vs ON.
3. `/graft activate <id>` turns thought on. Sleep does not delete.
4. `/graft fund 0.001` throws money at the GRAFT piggy (not V3 piggy).
5. `/graft think <id>` runs a visible step log and a derived brief.
6. Study `/graft log` + `/graft proof`. Mark `/graft survive` or `/graft die`.
7. `/graft harvest` means "candidate for later VITA study". It does not inject.

Last-root + directory loc slots stay empty until a human harvests a survivor.
No invented tx hashes.
