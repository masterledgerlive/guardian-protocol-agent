# Contributing

1. Read `HANDOFF.md` and `docs/CONSTITUTION.md`.
2. Keep changes inside `guardian-protocol/` unless explicitly coordinating a root injector change in a separate PR.
3. Add tests for simulator behavior.
4. Run `npm test` and `npm run benchmark`.
5. Declare assumptions in strategy submissions and reports.
6. Prefer smallest reproducible increments; prove superiority in the Arena before replacing baselines.
