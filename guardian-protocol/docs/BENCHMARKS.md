# Benchmarks

## Ladder

| ID | Object | Focus |
|---|---|---|
| 0001-tiny | Small lawful/public-domain object | Exact reconstruction, deterministic trace |
| 0002-book | Public-domain book | Overhead, encoding ratio, timings, cost |
| 0003-archive | Larger mixed dataset | Multi-node, repair, availability, concurrency |
| grand-challenge | Legally usable large A/V archive | Bit-exact, not merely playable approximation |

## Integrity requirements

- canonical input hash
- fixed benchmark version
- defined environment
- declared assumptions
- seeds where applicable
- complete trace
- output hash
- reconstruction proof
- cost accounting

Results from different benchmark versions must not be silently compared.
